# Quant Fun — Sprite map

Six original RGBA PNG sheets. There are 21 personas and 84 standing poses.
All sheets have four columns. Columns from left to right:
1. front-left
2. front-right
3. rear-left
4. rear-right

Rows are numbered from top to bottom. Use transparent gutters to find crop boundaries.
Preserve alpha. Normalize each sprite around a common foot baseline and body height.
These are directional standing poses.
